# CYBER SNAKE

赛博风格贪吃蛇小游戏 — 纯 HTML / CSS / JS，零依赖。

## 运行

双击 `index.html`，或在项目目录启动本地服务器：

```bash
python3 -m http.server 8080
```

浏览器打开 http://localhost:8080

## 操作

| 按键 | 功能 |
|------|------|
| `↑ ↓ ← →` 或 `W A S D` | 移动 |
| `Space` | 开始 / 重新开始 |
| `P` | 暂停 |

## 特性

- 霓虹赛博朋克视觉（扫描线、发光网格、粒子特效）
- 分数与最高分本地保存
- 随分数提升速度逐渐加快
